# Mobile-game-demon-cycle-

Demon Cycle - A mobile game for the demons cycle.

## Setup

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Open http://localhost:3000 in your browser. The game is touch-enabled for mobile devices.

## Build for Production

```bash
npm run build
```

Output will be in the `dist/` folder. Deploy to any static hosting.

## Game Controls

- **Mobile**: Tap/drag to move the demon, collect purple orbs (essence)
- **Desktop**: Mouse to move, or arrow keys

## Tech Stack

- Phaser 3 - Game framework
- Vite - Build tool
- HTML5 - Cross-platform (works in mobile browsers)
